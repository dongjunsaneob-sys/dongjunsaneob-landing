# 동준산업 랜딩페이지

동준산업의 포스터 이미지 중심 모바일 랜딩페이지 소스입니다. 이 저장소는 2026-08-20 기준으로 작성한 화면 개편본과 배포용 정적 자산을 보관합니다.

## 구성

| 경로 | 용도 |
|---|---|
| `index.html` | 랜딩페이지 마크업과 신청 폼 구조 |
| `styles.css` | 모바일 우선 포스터형 스타일 |
| `app.js` | 폼 검증, UTM 전달, 제출 동작 |
| `assets/support-poster.jpeg` | 첫 화면의 600만 원 지원 포스터 이미지 |
| `api/estimate.js` | 기존 운영 신청 API로 제출 데이터를 전달하는 미리보기용 프록시 |

## 로컬 확인

정적 서버로 프로젝트 루트를 열면 됩니다.

```bash
npx serve .
```

## 중요: 운영 배포 전 API 교체 필요

`api/estimate.js`는 현재 운영 중인 `https://dongjunsaneob-landing.vercel.app/api/estimate`로 데이터를 전달하는 **미리보기용 프록시**입니다. 이 파일을 `dongjunsaneob-landing` 운영 프로젝트에 그대로 프로덕션 배포하면 자기 자신을 호출하게 되어 신청·메일 전송이 중단될 수 있습니다.

운영 배포 전에는 기존 Vercel 프로젝트의 실제 `app/api/estimate` 구현을 복구하거나, 동일 기능의 독립적인 메일 전송 구현으로 교체해야 합니다. 이 저장소에는 Vercel에만 존재하던 기존 메일 전송 함수의 원본 코드는 포함되어 있지 않습니다.

## Vercel 연결 권장 방식

이 저장소를 GitHub에 푸시한 뒤 Vercel에서 `dongjunsaneob-landing` 프로젝트를 해당 저장소와 연결합니다. 실제 메일 전송 API 구현을 병합한 후에만 `main` 브랜치를 프로덕션 배포 대상으로 사용합니다. 그 전까지는 Preview Deployment로 화면만 검토합니다.

## 배포 전 확인 항목

- `/api/estimate`가 기존과 동일하게 이메일을 전송하는지 확인합니다.
- 실제 신청 데이터가 포함된 테스트를 하기 전, 수신 이메일과 개인정보 처리 문구를 검토합니다.
- `dongjuntotal.com` 통합 신청 링크와 전화 링크가 정상 동작하는지 확인합니다.
